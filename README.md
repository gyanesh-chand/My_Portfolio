## 🚀 Project Overview

This repository is the personal cybersecurity portfolio of **Gyanesh Chand** — a Cybersecurity Researcher, VAPT Intern, Web App Pentester, and Bug Bounty learner. The site is built with a modern dark neon aesthetic, glassmorphism UI, terminal-inspired sections and smooth animated interactions.

Key focus: professional, responsive, performance-optimized presentation of security work and projects.

- Animated Hero with typing effect

- About / Skills / Experience timeline
- Projects showcase with links

## 🧰 Tech Stack

- React.js (functional components + hooks)
- Vite (fast dev + build)
- Tailwind CSS (utility-first design)
- Framer Motion (animations)
- react-icons (icons)

Built with performance and responsiveness in mind — optimized images, minimal bundle, and small runtime animations.

## 🛠️ Installation

Clone the repo and install dependencies:

```bash
git clone https://github.com/gyanesh-chand/your-portfolio-repo.git
cd your-portfolio-repo
pnpm install
```

## ▶️ Run Locally

Start the development server (hot reloading):

```bash
pnpm dev
```

Build for production:

```bash
pnpm build
```

Preview production build locally:

```bash
pnpm preview
```
